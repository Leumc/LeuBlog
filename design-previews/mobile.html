二叉树入门：从定义到遍历

06/24Leu8 分钟阅读 1,284
目录 ▾
什么是二叉树基本性质如何表示遍历小结

二叉树是几乎所有高级数据结构的地基——堆、平衡树、线段树，无一不是它的变体。

基本性质

设高度为 $h$，则一棵二叉树最多包含的节点数为：

$$ n_{\max}=\sum_{i=1}^{h}2^{\,i-1}=2^{h}-1 $$

只要树高维持在 $O(\log n)$，查找/插入/删除便都是对数级。

如何表示

最直接的方式是链式结构：

C++ 
// 二叉树节点
struct Node {
    int val;
    Node *left, *right;
    Node(int v): val(v), left(nullptr), right(nullptr) {}
};

代码块超宽时横向滚动，不会撑破版面。
