# 设计预览存档（design-previews）

正式开发前，经可视化评审定稿的静态页面预览。**仅作实现时的视觉/交互参考**，
不参与 Next.js 构建、不放入 `public/`、不对外路由。

打开 `index.html` 可总览所有页面并跳转。

## 页面清单

| 文件 | 页面 | 要点 |
|---|---|---|
| `homepage.html` | 首页 | 暖纸底 + 暗砖红点缀；标题墨色、强调色克制；最近文章 + 公告条 + 侧栏传送门 |
| `categories.html` | 分组总览 | 每分组横向区块 + 底部标签云 |
| `category-detail.html` | 分组详情 | 组内子标签筛选 + 文章列表 + 分页 + 侧栏 |
| `tags.html` | 标签总览 | 「文章分组 → 标签组 → 标签」两级分层 |
| `archive.html` | 归档 | 跟随焦点层级侧栏（年→月→月历）+ 全年热力图；纯顶部检测 + 末尾留白 |
| `post.html` | 文章阅读页 | LaTeX(KaTeX) + 深色高对比代码块/复制按钮 + 右侧目录；小节标题无序号 |
| `about.html` | 关于 | 正文 + 数据一览 + 联系/传送门/colophon；内容取自后台设置 |
| `404.html` | 404 / 空状态 / 500 | 同一版式复用，仅改顶部主文案 |
| `admin.html` | 后台（全部页面） | 左导航切换：仪表盘/文章/编辑器/分类法/媒体/公告/传送门/用户/设置；实用优先 |
| `login.html` | 登录 | 衬线字标 + 无衬线表单；不开放公开注册 |
| `mobile.html` | 移动端适配 | 首页/文章/归档/后台 四屏窄屏布局示意 |

## 设计基准（摘要）

- **风格**：杂志质感，衬线字体，线条分隔（不用卡片阴影）。
- **配色**：纸底 `#faf7f1` / 次级 `#f6efe2`；墨色 `#2c2620`；强调 `#9c2b22`（暗砖红）+ 辅 `#c2592f` + 金 `#b08328`；细线 `#ddd5c5`。
- **后台**：实用优先，无衬线、紧凑、表格化，深色左导航，品牌红仅作强调。
- **代码块**：高对比暖色深色主题（底 `#272320`）。

> 注意：`post.html` / `mobile.html` 中的 LaTeX 用 KaTeX **CDN** 渲染（仅预览用）；
> 正式站点将自托管 KaTeX，不依赖外网。
