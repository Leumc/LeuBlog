二叉树入门：从定义到遍历

2026 年 6 月 24 日作者 Leu 阅读时长 8 分钟阅读 1,284

二叉树是几乎所有高级数据结构的地基——堆、平衡树、字典树、线段树，无一不是它的变体。理解它，等于拿到了通往一大片算法世界的钥匙。本文从最朴素的定义出发，讲清它的性质、表示与遍历。

什么是二叉树

二叉树（Binary Tree）是一种树形结构，其中每个节点至多有两个子节点，分别称为左子节点与右子节点。注意「左」「右」是有序的：交换两棵子树会得到一棵不同的二叉树。

一棵二叉树要么为空，要么由一个根节点和两棵互不相交的、分别称为左子树和右子树的二叉树组成——这是一个典型的递归定义。

几个常见的特殊形态：满二叉树（每一层都被填满）、完全二叉树（除最后一层外填满，且最后一层靠左）、平衡二叉树（左右子树高度差有界）。其中完全二叉树正是二叉堆用数组存储的基础。

基本性质

设二叉树的高度为 $h$（只有根节点时 $h=1$）。可以归纳证明，第 $i$ 层最多有 $2^{\,i-1}$ 个节点，于是一棵高度为 $h$ 的二叉树最多包含的节点数为：

$$ n_{\max} = \sum_{i=1}^{h} 2^{\,i-1} = 2^{h} - 1 $$

反过来，含有 $n$ 个节点的二叉树，其高度至少为 $\lceil \log_2 (n+1) \rceil$。这条下界解释了为什么平衡如此重要：只要树高维持在 $O(\log n)$，查找、插入、删除就都能做到 $O(\log n)$；一旦退化成链，复杂度便跌回 $O(n)$。

  • 满二叉树：节点数恰为 $2^{h}-1$；
  • 含 $n$ 个节点的完全二叉树高度为 $\lfloor \log_2 n \rfloor + 1$；
  • 任意二叉树中，度为 0 的节点数 $n_0$ 与度为 2 的节点数 $n_2$ 满足 $n_0 = n_2 + 1$。

如何表示一棵二叉树

最直接的方式是用链式结构：每个节点保存一个值和两个指向子节点的指针。

C++
// 二叉树节点的链式定义
struct Node {
    int val;
    Node *left, *right;
    Node(int v) : val(v), left(nullptr), right(nullptr) {}
};

对于完全二叉树，还可以用数组隐式存储：下标从 1 开始，节点 i 的左右孩子分别是 2*i 与 2*i+1，父节点是 i/2。二叉堆正是这样做的，省去了所有指针开销。

遍历：访问每一个节点

遍历是对二叉树最基本的操作，按访问根节点的时机分为三种深度优先方式：前序（根左右）、中序（左根右）、后序（左右根）。递归写法极其优雅：

C++
// 中序遍历：左 -> 根 -> 右
void inorder(Node* root) {
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->val << ' ';   // 访问根
    inorder(root->right);
}

每个节点恰好被访问一次，因此三种遍历的时间复杂度均为 $O(n)$，空间复杂度取决于递归栈深度，即树高 $O(h)$。若想避免递归，可以用一个显式栈改写；而层序遍历（广度优先）则需要借助队列：

C++
// 层序遍历：借助队列逐层访问
void levelOrder(Node* root) {
    if (!root) return;
    queue<Node*> q;
    q.push(root);
    while (!q.empty()) {
        Node* cur = q.front(); q.pop();
        cout << cur->val << ' ';
        if (cur->left)  q.push(cur->left);
        if (cur->right) q.push(cur->right);
    }
}

小结

从一个递归定义出发，我们看到了二叉树如何用 $2^{h}-1$ 约束规模、如何用链式或数组表示、又如何用四种顺序被遍历。把这些基本功握牢，再去看堆、BST、线段树时，你会发现它们不过是在这棵朴素的树上长出的新枝。
